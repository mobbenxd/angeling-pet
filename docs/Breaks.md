# เตือนให้พักและดื่มน้ำ

Angeling นับว่าคุณใช้เครื่องต่อเนื่องมานานแค่ไหน แล้วชวนพักเมื่อถึงเวลา และเตือนให้ดื่มน้ำเป็นระยะ ทั้งสองอย่าง**ปิดอยู่**จนกว่าจะเปิดในตั้งค่า

## เปิดใช้

**ตั้งค่า… → แจ้งเตือน → พักและดื่มน้ำ**

| ตัวเลือก | ผลลัพธ์ | ค่าเริ่มต้น |
|---|---|---|
| เตือนให้พัก | เปิดหรือปิดการเตือนให้พัก | ปิด |
| เมื่อทำงานต่อเนื่อง | เตือนเมื่อใช้เครื่องต่อเนื่องครบ 25, 30, 45, 50, 60 หรือ 90 นาที | 50 นาที |
| นับว่าพักเมื่อไม่แตะเครื่อง | ไม่แตะคีย์บอร์ดและเมาส์นาน 3, 5, 10 หรือ 15 นาที ถือว่าพักแล้ว | 5 นาที |
| เตือนให้ดื่มน้ำ | เปิดหรือปิดการเตือนให้ดื่มน้ำ | ปิด |
| ทุก | เตือนดื่มน้ำทุก 30, 45, 60, 90 หรือ 120 นาที | 60 นาที |

## เตือนให้พัก

เมื่อใช้เครื่องต่อเนื่องครบเวลา Angeling จะโผล่ออกมา (แม้จะซ่อนอยู่) โบกมือ แสดง emote `/swt` ส่งเสียงเตือน 1 ครั้ง และขึ้นแถวสีส้ม **☕ พักสักหน่อยนะ** พร้อมบอกว่าทำงานมากี่นาที

| ทำอะไร | ผลลัพธ์ |
|---|---|
| ลุกไปพักจนครบเวลา | แถวหายเอง และเริ่มนับรอบใหม่เมื่อกลับมา |
| คลิกแถว | พักแล้ว: เริ่มนับรอบใหม่ |
| คลิกขวา → เตือนอีกครั้งใน 5 / 10 / 15 นาที | เลื่อนการเตือน |
| คลิกขวา → ปิดการเตือนให้พัก | ปิดฟีเจอร์นี้ |
| เมนู → ☕ พักแล้ว (ทำงานมา N จาก M นาที) | ดูว่าทำงานมานานแค่ไหน คลิกเพื่อเริ่มนับรอบใหม่ |

Angeling นับเวลาจากการใช้คีย์บอร์ดและเมาส์ จึงไม่ต้องขอสิทธิ์เพิ่ม และไม่รู้ว่าคุณพิมพ์หรือคลิกอะไร เครื่องหลับหรือล็อกจอนานครบเวลาพักก็นับว่าพักแล้ว

## เตือนให้ดื่มน้ำ

เมื่อครบเวลา Angeling จะโบกมือ แสดง emote `/slur` และขึ้นแถว **💧 ดื่มน้ำหน่อยนะ** โดยไม่มีเสียง แถวบอกด้วยว่าวันนี้ดื่มไปแล้วกี่แก้ว

| ทำอะไร | ผลลัพธ์ |
|---|---|
| คลิกแถว | ดื่มแล้ว: นับเพิ่ม 1 แก้ว และเริ่มนับรอบใหม่ |
| คลิกขวา → เตือนอีกครั้งใน 5 / 10 / 15 นาที | เลื่อนการเตือน |
| คลิกขวา → ปิดการเตือนให้ดื่มน้ำ | ปิดฟีเจอร์นี้ |

จำนวนแก้วเริ่มนับใหม่ทุกวัน ถ้าคุณไม่อยู่หน้าจอตอนครบเวลา Angeling จะรอเตือนเมื่อคุณกลับมา

## ไม่เตือนตอนไหน

- **ระหว่างนัดในปฏิทิน** ทั้งสองอย่างรอจนนัดจบ (ต้องเปิด[นัดถัดไปจากปฏิทิน](Meetings.md)ไว้)
- **ตอนไม่ได้ใช้เครื่อง** เพราะถือว่าพักอยู่แล้ว

## ข้อควรรู้

- ดูวิดีโอหรือประชุมโดยไม่แตะคีย์บอร์ดและเมาส์นานครบเวลาพัก Angeling จะนับว่าพักแล้ว
- ปิดแล้วเปิด Angeling ใหม่ จะเริ่มนับเวลาทำงานใหม่
- เสียงเตือนใช้ค่าเดียวกับ ตั้งค่า… → แจ้งเตือน → เสียงเตือน
