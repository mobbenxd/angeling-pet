# เปลี่ยนเป็นเพ็ตตัวอื่น

## เลือกตัวละคร Bomber

เมนู → **ตั้งค่า… → หน้าตา** ส่วน **ตัวละคร** กลุ่มแรกคือ Angeling, Bee Husky (ลูกหมาไซบีเรียนฮัสกี้) และ Banana Dog (หมาตัวเป็นกล้วย) ที่ทำท่าได้ครบเหมือน Angeling กลุ่มที่สองคือตัวละครจากเกม Bomber 18 ตัว:
Thunder, Bomber Horse, Bomber Husky, Bomber Cat, Cool Pomeranian, Pumpkin Raccoon, Chubby Valkyrie, Chubby Drake, Chubby Mage, Chubby Beerus, Chubby Legend, Carrot Engineer, Sun Sage, Noid, Chick Squad, Chubby Cloudy, Tommy Shelby, Charles Leclerc

คลิกที่รูปเพื่อใช้ตัวนั้น ตัวละครเปลี่ยนและโบกมือทันทีและจำไว้หลังเปิดแอปใหม่ ท่าทางของตัวละคร Bomber:

| สถานะ | ท่า |
|---|---|
| ว่าง / กำลังทำงาน | เดินหันหน้าเข้าหาเรา |
| รอคำตอบ / โบกมือ / กระโดด | ท่าวางระเบิด |
| ผิดพลาด | ท่าโดนระเบิด กะพริบ |
| ลากไปมา | เดินซ้ายหรือขวา |

ถ้าไม่เห็นส่วนนี้ แปลว่ายังไม่มีไฟล์ตัวละคร ให้[อัปเดต](Updating-and-Uninstalling.md)เป็นเวอร์ชันล่าสุด

Angeling ใช้ sprite sheet แบบเดียวกับเพ็ตของ Codex (รูปแบบ v2) จึงใช้เพ็ต Codex ตัวไหนก็ได้

## ใช้เพ็ตตัวอื่นจาก Codex

```bash
ls ~/.codex/pets/                  # ดูชื่อเพ็ตที่มี
cd ~/apps/angeling-pet
rm assets/spritesheet.webp
ANGELING_CODEX_PET=<ชื่อเพ็ต> ./install.sh   # ต้องใช้วิธี build จากซอร์ส (git clone)
```

## ใช้ไฟล์ของคุณเอง

วางไฟล์ไว้ที่ `assets/spritesheet.webp` (หรือ PNG ที่เปลี่ยนชื่อเป็นนามสกุลนี้) แล้วรัน `./install.sh`

| สเปก | ค่า |
|---|---|
| ขนาดภาพ | 1536 × 2288 px |
| ตาราง | 8 คอลัมน์ × 11 แถว |
| ขนาดช่อง | 192 × 208 px |

| แถว | ท่า |
|---|---|
| 0 | idle |
| 1 | running-right |
| 2 | running-left |
| 3 | waving |
| 4 | jumping |
| 5 | failed |
| 6 | waiting |
| 7 | running |
| 8 | review |
| 9–10 | มองไปรอบๆ |

## เพิ่มเพ็ตที่สร้างเองเข้ารายการตัวละคร

ถ้าให้ AI สร้าง sprite sheet มา ภาพมักผิดขนาดหรือแถวไม่ตรงช่อง สคริปต์นี้จะหาแต่ละเฟรมเอง แล้ววางลงช่อง 192 × 208 ให้พอดี (ต้องมีแถวครบ 11 แถว และจำนวนเฟรมแต่ละแถวตรงตามตาราง: 7, 8, 8, 4, 5, 8, 6, 6, 6, 8, 8 ถ้าแถวไหนขาดไม่เกิน 2 เฟรม สคริปต์จะใช้เฟรมสุดท้ายซ้ำ และถ้าเฟรมวาดชิดกันจนติด สคริปต์จะตัดแยกให้):

```bash
swift scripts/import-pet.swift ~/Downloads/my-pet.png my-pet "My Pet"
./install.sh
```

เพ็ตจะไปอยู่ที่ `~/.claude/angeling-pet/pets/my-pet/` และขึ้นในรายการ **ตัวละคร** (ตั้งค่า… → หน้าตา) หลังเปิดแอปใหม่ จะคัดลอกโฟลเดอร์เพ็ตของ Codex (`~/.codex/pets/<ชื่อ>/`) ไปวางที่นั่นตรงๆ ก็ได้

## เพิ่มเฟรมให้ท่าลื่นขึ้น

เพ็ตในโฟลเดอร์ `pets/` กำหนดจำนวนเฟรมและความเร็วของแต่ละท่าเองได้ ใส่ `animations` ใน `pet.json`:

```json
"animations": {
  "idle": { "frames": 16, "ms": 90 },
  "running": { "frames": 12, "ms": 70 }
}
```

- `frames` คือจำนวนเฟรม (1–16) เรียงจากซ้ายไปขวาในแถวเดิมของท่านั้น ถ้าเกิน 8 เฟรม sheet ต้องกว้างขึ้น (16 คอลัมน์ = 3072 px)
- `ms` คือเวลาที่แสดงแต่ละเฟรม หน่วยมิลลิวินาที
- ท่าที่ไม่ได้ใส่ใช้จำนวนเฟรมและความเร็วตามตารางเดิม

ไฟล์แบบนี้ใช้ได้กับ Angeling เท่านั้น Codex จะอ่านเฟรมที่เกิน 8 ไม่ได้

ชื่อแอปและไอคอนในแถบเมนูยังเป็น Angeling แต่ภาพตัวละครจะเปลี่ยนตามไฟล์ใหม่
