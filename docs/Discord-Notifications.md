# แจ้งเตือน Discord

Angeling แสดงแถวสีม่วง **🎮 Discord** บอก **จำนวนข้อความที่ยังไม่อ่าน** โดยไม่อ่านเนื้อหาข้อความใดๆ

ตัวเลขนี้คือตัวเลขเดียวกับป้ายสีแดงบนไอคอน Discord ใน Dock ซึ่งนับ:
- **DM** (ข้อความส่วนตัวและกลุ่ม DM)
- **การ @mention คุณ** ในเซิร์ฟเวอร์

ข้อความทั่วไปในเซิร์ฟเวอร์ที่ไม่ได้ mention คุณ (ที่ Discord แสดงเป็นจุด `•`) จะไม่ถูกนับ

## ตั้งค่า

ไม่ต้องตั้งค่าอะไร ไม่ต้องให้สิทธิ์เพิ่ม แค่เปิดแอป **Discord** ไว้ (ปิดหน้าต่างได้ แต่อย่า Quit) ถ้า Quit Discord แถวจะหายไป

## อยากให้นับแค่ DM

Angeling ไม่อ่านข้อความ จึงแยก DM ออกจาก @mention ไม่ได้ แต่ปรับที่ Discord ได้ว่าเซิร์ฟเวอร์ไหนจะไม่นับ:
- คลิกขวาที่ไอคอนเซิร์ฟเวอร์ → **Notification Settings** → เลือก **Nothing**
- หรือติ๊ก **Suppress @everyone and @here** และ **Suppress All Role @mentions**

## การใช้งาน

| ทำอะไร | ผลลัพธ์ |
|---|---|
| คลิกแถว Discord | เปิด Discord |
| คลิกขวา → ซ่อนจนกว่าจะมีข้อความใหม่ | แถวหายไป แล้วกลับมาเมื่อตัวเลขเพิ่มขึ้น |
| คลิกขวา → ปิดแจ้งเตือน Discord | ปิดฟีเจอร์ (เปิดใหม่ได้ที่เมนู "แจ้งเตือน Discord") |
| ซ่อนบับเบิล | ป้ายสีม่วงทางซ้ายของ Angeling แสดงจำนวน |

เมื่อมีข้อความใหม่ Angeling จะแสดง emote `/heh` ด้วย เมื่ออ่านใน Discord แล้ว ตัวเลขจะลดลงเอง

## แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ไม่มีแถว Discord | Discord ไม่ได้เปิดอยู่ ไม่มีข้อความค้าง หรือปิดฟีเจอร์ไว้ |
| ไอคอน Discord ใน Dock ไม่มีตัวเลข | เช็คว่า System Settings → Notifications → Discord เปิด **Badge application icon** ไว้ |
