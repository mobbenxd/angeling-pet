# เริ่มใช้งานครั้งแรก

## 1. ลองตั้งเตือน (ไม่ต้องมี Claude)

1. กด **⌥⌘R**
2. พิมพ์ `ลองเตือน` แล้วกด `+15 นาที` ซ้ำๆ จนได้เวลาที่ต้องการ (หรือพิมพ์เวลาให้ห่างจากตอนนี้ 1–2 นาที)
3. กด **ตั้งเตือน** ครั้งแรก macOS จะถามสิทธิ์ปฏิทิน ให้กด **Allow Full Access**
4. พอถึงเวลา Angeling จะกระโดด และเปิดเสียง Level Up ของ Ragnarok พร้อมแถวสีส้ม คลิกแถวเพื่อรับทราบ

รายละเอียดดูที่ [ตั้งเตือน](Reminders.md)

## 2. ถ้าใช้ LINE หรือ Discord

เปิดแอป LINE ไว้ แถว 💬 LINE จะบอกจำนวนข้อความที่ยังไม่อ่าน ถ้าอยากเห็นข้อความด้วย ดู [แจ้งเตือน LINE](LINE-Notifications.md)

เปิดแอป Discord ไว้ แถว 🎮 Discord จะบอกจำนวน DM และ @mention ที่ยังไม่อ่าน ดู [แจ้งเตือน Discord](Discord-Notifications.md)

## 3. ถ้าใช้ Claude Code: ให้ทำงานสักอย่าง

เปิด Claude Code ทางใดทางหนึ่งก็ได้:
- **แอป Claude desktop** แท็บ Code
- **Terminal / iTerm2:** รัน `claude`
- **VS Code / Cursor / Windsurf:** ใช้ terminal ในตัว editor

แล้วสั่งงานอะไรก็ได้ เช่น `อ่าน README แล้วสรุปให้หน่อย`

Session ที่เปิดอยู่ก่อนติดตั้งก็ใช้ได้เลย ไม่ต้องรีสตาร์ต เพราะ Claude Code อ่าน hook ใหม่ทันที

## 4. ดู Angeling รายงาน

| จังหวะ | สิ่งที่เห็น |
|---|---|
| ส่งงาน | บับเบิลขึ้น "⚙️ ชื่อโปรเจกต์ · กำลังทำ" + emote `/heh` |
| Claude อ่านหรือค้นไฟล์ | "🔍 ตรวจดู" พร้อมชื่อไฟล์ |
| Claude ขออนุญาต | แถวกรอบแดงกะพริบ "⚠️ ต้องดูตอนนี้" + เสียงเตือน + ป้าย "!" + emote `/wah` ค้างไว้จนกว่าจะตอบ |
| งานเสร็จ | แถวกรอบเขียว "✨ เสร็จแล้ว" พร้อมข้อความสรุปของ Claude + emote `/lv` |

## 5. ลองคลิก

- **คลิกแถว** → เปิดหน้าต่างของ session นั้น
- **คลิก Angeling** → เปิด session ที่ทำงานล่าสุด
- **ชี้ที่ Angeling** → มีปุ่มเล็กๆ ทางซ้ายสำหรับซ่อนหรือแสดงบับเบิล

## 6. ปรับตามชอบ

- ลาก Angeling ไปวางมุมไหนก็ได้ ตำแหน่งจะถูกจำไว้
- คลิกขวาที่ Angeling เพื่อเลือกว่าบับเบิลจะแสดงอะไร
- อยากเห็นข้อความ LINE ด้วย? ดู [แจ้งเตือน LINE](LINE-Notifications.md)
