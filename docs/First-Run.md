# เริ่มใช้งานครั้งแรก

## 1. ให้ Claude Code ทำงานสักอย่าง

เปิด Claude Code ทางใดทางหนึ่งก็ได้:
- **แอป Claude desktop** แท็บ Code
- **Terminal / iTerm2:** รัน `claude`
- **VS Code / Cursor / Windsurf:** ใช้ terminal ในตัว editor

แล้วสั่งงานอะไรก็ได้ เช่น `อ่าน README แล้วสรุปให้หน่อย`

Session ที่เปิดอยู่ก่อนติดตั้งก็ใช้ได้เลย ไม่ต้องรีสตาร์ต เพราะ Claude Code อ่าน hook ใหม่ทันที

## 2. ดู Angeling รายงาน

| จังหวะ | สิ่งที่เห็น |
|---|---|
| ส่งงาน | บับเบิลขึ้น "⚙️ ชื่อโปรเจกต์ · กำลังทำ" + emote `/heh` |
| Claude อ่านหรือค้นไฟล์ | "🔍 ตรวจดู" พร้อมชื่อไฟล์ |
| Claude ขออนุญาต | "🙋 รอคุณ" + emote `/wah` ค้างไว้จนกว่าจะตอบ |
| งานเสร็จ | แถวกรอบเขียว "✨ เสร็จแล้ว" พร้อมข้อความสรุปของ Claude + emote `/lv` |

## 3. ลองคลิก

- **คลิกแถว** → เปิดหน้าต่างของ session นั้น
- **คลิก Angeling** → เปิด session ที่ทำงานล่าสุด
- **ชี้ที่ Angeling** → มีปุ่มเล็กๆ ทางซ้ายสำหรับซ่อนหรือแสดงบับเบิล

## 4. ปรับตามชอบ

- ลาก Angeling ไปวางมุมไหนก็ได้ ตำแหน่งจะถูกจำไว้
- คลิกขวาที่ Angeling เพื่อเลือกว่าบับเบิลจะแสดงอะไร
- อยากเห็นข้อความ LINE ด้วย? ดู [แจ้งเตือน LINE](LINE-Notifications.md)
