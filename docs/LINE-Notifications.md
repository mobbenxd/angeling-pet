# แจ้งเตือน LINE

Angeling แสดงแถวสีเขียว **💬 LINE** ไว้บนสุดของบับเบิล บอก:
- **จำนวนข้อความที่ยังไม่อ่านทั้งหมด** (ตัวเลขเดียวกับป้ายบนไอคอน LINE ใน Dock)
- **ข้อความล่าสุด**: ชื่อห้อง · ผู้ส่ง, เวลา และเนื้อความ

คลิกแถวเพื่อเปิด LINE แถวจะแสดงเฉพาะตอนที่มีข้อความยังไม่อ่านเท่านั้น

## ตั้งค่า

### ขั้นที่ 1: จำนวนที่ยังไม่อ่าน (ไม่ต้องตั้งอะไร)
แค่เปิดแอป **LINE for Mac** ทิ้งไว้ ตัวเลขจะขึ้นเอง ถ้าปิด LINE แถวจะหายไป

### ขั้นที่ 2: ข้อความล่าสุด (ต้องให้สิทธิ์ Full Disk Access)
ข้อความถูกอ่านจากฐานข้อมูลของ Notification Center ซึ่ง macOS ป้องกันไว้

1. เปิด **System Settings → Privacy & Security → Full Disk Access**
   (หรือคลิกขวาที่แถว LINE → "ให้สิทธิ์ Full Disk Access…")
2. กด **+** แล้วเลือก `~/Applications/Angeling.app`
   (กด ⌘⇧G แล้วพิมพ์ `~/Applications` ถ้าหาไม่เจอ)
3. เปิดสวิตช์ของ Angeling
4. ปิดแล้วเปิด Angeling ใหม่: เมนู → ปิด Angeling แล้วรัน `open ~/Applications/Angeling.app`

### ขั้นที่ 3: เช็คการตั้งค่าใน LINE
- LINE → Settings → Notifications: **เปิดการแจ้งเตือน**
- ถ้าอยากเห็นเนื้อความ ต้องเปิด **แสดงตัวอย่างข้อความ (message preview)** ด้วย
- System Settings → Notifications → LINE: ต้อง **Allow notifications**

## การใช้งาน

| ทำอะไร | ผลลัพธ์ |
|---|---|
| คลิกแถว LINE | เปิด LINE |
| คลิกขวา → ซ่อนจนกว่าจะมีข้อความใหม่ | แถวหายไป แล้วกลับมาเมื่อมีข้อความใหม่ |
| คลิกขวา → ปิดแจ้งเตือน LINE | ปิดทั้งฟีเจอร์ (เปิดใหม่ได้ที่เมนู "แจ้งเตือน LINE") |
| ซ่อนบับเบิล | ป้ายสีเขียวทางซ้ายของ Angeling แสดงจำนวนที่ยังไม่อ่าน |

## หมายเหตุ

- **หลัง build หรือติดตั้งใหม่ ต้องให้สิทธิ์ Full Disk Access ซ้ำ** เพราะ Angeling เซ็นแบบ ad-hoc macOS จึงมองว่าเป็นแอปใหม่ ให้ลบ Angeling ออกจากรายการแล้วเพิ่มใหม่
- Angeling อ่านอย่างเดียว ไม่แก้ไขอะไร ไม่ส่งข้อมูลออกนอกเครื่อง และอัปเดตทุก 3 วินาที
- "ข้อความล่าสุด" คือแจ้งเตือนล่าสุดที่ยังอยู่ใน Notification Center ถ้าล้างแจ้งเตือนหรืออ่านใน LINE แล้ว อาจเห็นข้อความเก่ากว่าแทน

## แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ไม่มีแถว LINE เลย | LINE ไม่ได้เปิดอยู่ ไม่มีข้อความค้าง หรือปิดฟีเจอร์ไว้ (เมนู "แจ้งเตือน LINE") |
| มีแต่จำนวน ไม่มีข้อความ | ยังไม่ได้ให้ Full Disk Access หรือให้แล้วแต่ยังไม่ได้เปิด Angeling ใหม่ หรือ build ใหม่หลังให้สิทธิ์ |
| ขึ้นแต่ชื่อ ไม่มีเนื้อความ | ปิด message preview ไว้ใน LINE |
| จำนวนไม่ตรงกับในแอป | Angeling ใช้ตัวเลขเดียวกับป้ายใน Dock ของ LINE ถ้า LINE ปิดป้ายไว้ ตัวเลขจะเป็น 0 |
