# แจ้งเตือน LINE

Angeling แสดงแถวสีเขียว **💬 LINE** บอก **จำนวนข้อความที่ยังไม่อ่านทั้งหมด** โดยไม่อ่านเนื้อหาข้อความใดๆ

ตัวเลขนี้คือตัวเลขเดียวกับป้ายบนไอคอน LINE ใน Dock แถวจะแสดงเฉพาะตอนที่มีข้อความที่ยังไม่อ่าน

## ตั้งค่า

ไม่ต้องตั้งค่าอะไร และไม่ต้องให้สิทธิ์เพิ่ม แค่เปิดแอป **LINE for Mac** ทิ้งไว้ (ปิดหน้าต่างได้ แต่อย่า Quit) ถ้า Quit LINE แถวจะหายไป

## การใช้งาน

| ทำอะไร | ผลลัพธ์ |
|---|---|
| คลิกแถว LINE | เปิด LINE |
| คลิกขวา → ซ่อนจนกว่าจะมีข้อความใหม่ | แถวหายไป แล้วกลับมาเมื่อตัวเลขเพิ่มขึ้น |
| คลิกขวา → ปิดแจ้งเตือน LINE | ปิดฟีเจอร์ (เปิดใหม่ได้ที่เมนู "แจ้งเตือน LINE") |
| ซ่อนบับเบิล | ป้ายสีเขียวทางซ้ายของ Angeling แสดงจำนวนที่ยังไม่อ่าน |

## แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ไม่มีแถว LINE เลย | LINE ไม่ได้เปิดอยู่ ไม่มีข้อความค้าง หรือปิดฟีเจอร์ไว้ (เมนู "แจ้งเตือน LINE") |
| จำนวนไม่ตรงกับในแอป | Angeling ใช้ตัวเลขเดียวกับป้ายบนไอคอน LINE ใน Dock ถ้าปิดป้ายไว้ (System Settings → Notifications → LINE → Badge application icon) ตัวเลขจะเป็น 0 |
