# นัดถัดไปจากปฏิทิน

Angeling อ่านนัดจากแอป Calendar แล้วบอกเมื่อใกล้ถึงเวลา คลิกแถวนัดเพื่อเข้าประชุมออนไลน์ได้เลย

- **ก่อนเริ่ม 15 นาที** (ปรับได้) มีแถว "📅 อีก N นาที" ขึ้นในบับเบิล พร้อมชื่อนัดและเวลาเริ่ม–จบ
- **ก่อนเริ่ม 1 นาที** แถวเปลี่ยนเป็นสีส้ม Angeling โผล่ออกมา (แม้จะซ่อนอยู่) แสดง emote `/omg` และส่งเสียงเตือน 1 ครั้ง
- **หลังเริ่ม** แถว "เริ่มแล้ว N นาที" ค้างไว้อีก 10 นาที (หรือจนนัดจบ) เผื่อเข้าช้า

Angeling อ่านปฏิทินอย่างเดียว ไม่แก้ไขนัด และข้อมูลนัดไม่ออกจากเครื่อง

## เปิดใช้

ฟีเจอร์นี้เปิดอยู่แล้ว และใช้สิทธิ์ปฏิทินเดียวกับ[การตั้งเตือน](Reminders.md) ถ้ายังไม่เคยให้สิทธิ์ ไปที่ **ตั้งค่า… → แจ้งเตือน → ปฏิทิน → ให้สิทธิ์…** แล้วกด **Allow Full Access**

**ตั้งค่า… → แจ้งเตือน → นัดจากปฏิทิน**

| ตัวเลือก | ผลลัพธ์ |
|---|---|
| แสดงนัดถัดไปจากปฏิทิน | เปิดหรือปิดฟีเจอร์นี้ |
| แสดงล่วงหน้า | ให้แถวนัดขึ้นก่อนเริ่ม 5, 10, 15, 30 นาที หรือ 1 ชั่วโมง |

## นัด MS Teams / Outlook

นัดของ Teams และ Outlook อยู่ในบัญชีงาน Microsoft 365 Angeling จะเห็นก็ต่อเมื่อเพิ่มบัญชีนั้นให้แอป Calendar ของ Mac ก่อน ขั้นตอนเดียวกันนี้อยู่ใน **ตั้งค่า… → แจ้งเตือน → นัดจากปฏิทิน → นัด MS Teams / Outlook ไม่ขึ้น?** พร้อมปุ่มเปิดหน้าที่ต้องใช้

1. เปิด **System Settings → Internet Accounts** (หรือกดปุ่ม **เปิด Internet Accounts…** ในหน้าตั้งค่าของ Angeling)
2. กด **Add Account…** แล้วเลือก **Microsoft Exchange**
3. ล็อกอินด้วยอีเมลงาน (อันเดียวกับที่ใช้ใน Teams)
4. เปิดสวิตช์ **Calendars** ของบัญชีนั้น
5. เปิดแอป Calendar รอให้นัด Teams ขึ้น แล้ว Angeling จะเห็นภายใน 1 นาที

**ถ้าองค์กรไม่ให้เพิ่มบัญชี** ให้สมัครรับปฏิทินแบบ ICS แทน:

1. ใน Outlook บนเว็บ ไปที่ **Settings → Calendar → Shared calendars → Publish a calendar**
2. เลือกปฏิทิน และเลือก **Can view all details** (ถ้าเลือกแบบอื่น ลิงก์ประชุมจะไม่มา) แล้วคัดลอกลิงก์ **ICS**
3. ในแอป Calendar ไปที่ **File → New Calendar Subscription…** แล้ววางลิงก์

วิธี ICS นัดใหม่จะมาช้าตามรอบรีเฟรชของ Calendar และบางองค์กรปิดการ Publish ไว้

## ใช้งาน

| ทำอะไร | ผลลัพธ์ |
|---|---|
| คลิกแถวนัดที่มีลิงก์ประชุม | เปิดลิงก์ประชุม แล้วแถวหายไป |
| คลิกแถวนัดที่ไม่มีลิงก์ | เปิดแอป Calendar |
| คลิกขวา → ซ่อนนัดนี้ | แถวหายไป (นัดในปฏิทินยังอยู่) |
| คลิกขวา → ปิดการแสดงนัดจากปฏิทิน | ปิดฟีเจอร์นี้ |
| เมนู → 📅 นัดถัดไป (N) | ดูนัดถึงสิ้นวันพรุ่งนี้ (สูงสุด 10 นัด) คลิกเพื่อเข้าประชุม |

เมื่อซ่อนบับเบิลไว้ แถวนัดจะขึ้นตั้งแต่ 1 นาทีก่อนเริ่ม

## ลิงก์ประชุมที่รู้จัก

Angeling หาลิงก์จากช่อง URL, สถานที่ และโน้ตของนัด ตามลำดับ และเปิดเฉพาะลิงก์ของบริการเหล่านี้: Zoom, Google Meet, Microsoft Teams, Webex, Whereby, GoTo, Amazon Chime, Jitsi, FaceTime, Discord, Slack และ LINE

## นัดที่ไม่แสดง

- นัดทั้งวัน
- นัดที่ถูกยกเลิก หรือที่คุณตอบปฏิเสธ
- นัดที่ Angeling สร้างจาก[การตั้งเตือน](Reminders.md) (เพราะมีแถวเตือนของตัวเองอยู่แล้ว)

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| ไม่มีแถวนัดขึ้น | เช็คว่าให้สิทธิ์ปฏิทินแล้ว และนัดอยู่ในแอป Calendar ของเครื่องนี้ (บัญชี Google ต้องเพิ่มใน Internet Accounts ก่อนเช่นกัน) |
| นัด MS Teams หรือ Outlook ไม่ขึ้น | ทำตามหัวข้อ "นัด MS Teams / Outlook" ด้านบน |
| เมนูขึ้น "ยังไม่ได้รับสิทธิ์เข้าถึงปฏิทิน" | ให้สิทธิ์ตามหัวข้อ "เปิดใช้" ด้านบน |
| แถวขึ้น "คลิกเพื่อเปิด Calendar" ทั้งที่มีลิงก์ | ลิงก์ไม่ใช่ของบริการที่รู้จัก หรืออยู่นอกช่อง URL, สถานที่ และโน้ต |
| ไม่ได้ยินเสียง | เสียงใช้ค่าเดียวกับ ตั้งค่า… → แจ้งเตือน → เสียงเตือน เช็คว่าไม่ได้เลือก "ปิดเสียง" |
