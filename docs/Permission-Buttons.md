# ตอบคำขออนุญาตของ Claude Code จาก Angeling

เวลา Claude Code ขออนุญาตรันคำสั่ง แก้ไฟล์ หรือเข้าเว็บ บับเบิลจะขึ้นแถวสีแดง 🔐 พร้อมคำสั่งที่จะรันและปุ่มให้กดได้ทันที ไม่ต้องสลับไปหน้าต่าง terminal

| ปุ่ม | ผล |
|---|---|
| **อนุญาต** | ให้ทำครั้งนี้ |
| **ไม่ต้องถามอีก** | อนุญาต และบันทึกกฎตามที่ Claude Code เสนอ (เหมือนเลือก "Yes, and don't ask again" ใน terminal) ขึ้นเฉพาะคำขอที่ Claude Code มีตัวเลือกนี้ |
| **ปฏิเสธ** | ไม่ให้ทำ Claude จะรู้ว่าคุณปฏิเสธจาก Angeling แล้วทำงานต่อ |

กดที่ข้อความในแถว (ไม่ใช่ปุ่ม) เพื่อไปที่ session นั้นแทน

## ดูก่อนว่าจะแก้อะไร

คำขอแก้ไฟล์ (Edit, MultiEdit, Write, NotebookEdit) จะมีตัวอย่างการเปลี่ยนแปลงใต้ชื่อไฟล์: จำนวนบรรทัดที่เพิ่ม (`+`, สีเขียว) และลบ (`−`, สีแดง) และบรรทัดที่เปลี่ยนสูงสุด 10 บรรทัด ส่วนที่ไม่เปลี่ยนย่อเป็น `⋯` ถ้า Write ทับไฟล์ที่มีอยู่ Angeling จะเทียบกับไฟล์เดิมในเครื่อง (ไฟล์ไม่เกิน 512 KB)

## ตอบคำถามของ Claude

เวลา Claude ถามแบบมีตัวเลือก (AskUserQuestion) แถว 🔐 จะขึ้นว่า **ถามคุณ** พร้อมคำถามและตัวเลือกเป็นปุ่ม ชี้ที่ปุ่มเพื่อดูคำอธิบายของตัวเลือก

- คำถามเดียวแบบเลือกข้อเดียว: กดตัวเลือกแล้วส่งเลย
- หลายคำถาม (Claude ถามได้ครั้งละ 1–4 ข้อ): ขึ้น**ทีละข้อ** หัวแถวบอกว่าอยู่ข้อไหน เช่น `ข้อ 2/4 ●●○○` กดตัวเลือกแล้วไปข้อถัดไปเอง และมี **← ย้อนกลับ** ไว้แก้คำตอบ
- ข้อที่เลือกได้หลายข้อ (☐ / ☑): ติ๊กให้ครบแล้วกด **ถัดไป →** (ถ้ามีคำถามเดียวจะเป็นปุ่ม **ส่งคำตอบ**)
- ตอบครบแล้วจะขึ้น **สรุปคำตอบ** ให้ดูอีกที แล้วกด **ส่งคำตอบ**
- อยากพิมพ์คำตอบเอง: กดที่ข้อความในแถวเพื่อไปตอบใน Claude Code

ถ้า Claude มีเรื่องจะถามเกิน 4 ข้อ จะถามเป็นหลายรอบ แต่ละรอบขึ้นเป็นคำขอใหม่หลังตอบรอบก่อน

## คีย์ลัด

ใช้ได้เฉพาะตอนมีคำขอรออยู่ (นอกจากนั้นคีย์พวกนี้เป็นของแอปอื่นตามปกติ) และใช้กับคำขอที่เก่าที่สุด ซึ่งเป็นแถวที่มีคำใบ้คีย์ลัดอยู่

| คีย์ | คำขออนุญาต | คำถาม |
|---|---|---|
| ⌥⌘Y | อนุญาต | ถัดไป (ข้อที่เลือกได้หลายข้อ) หรือส่งคำตอบ (หน้าสรุป) |
| ⌥⌘N | ปฏิเสธ | ไม่ตอบ (Claude จะทำงานต่อโดยไม่ได้คำตอบ) |
| ⌥⌘1 – ⌥⌘4 | – | เลือกตัวเลือกที่ 1–4 ของข้อที่อยู่บนจอ |

## ตอบที่ไหนก่อนก็ได้

กล่องถามของ Claude Code ใน terminal หรือในแอป Claude ยังขึ้นตามปกติพร้อมกัน ตอบฝั่งไหนก่อน ฝั่งนั้นชนะ ถ้าตอบใน terminal แถวใน Angeling จะหายไปเอง

ถ้าไม่ตอบเลย ปุ่มใน Angeling จะหายไปหลัง 10 นาที แต่กล่องถามใน Claude Code ยังรออยู่

## เปิด / ปิด

ตั้งค่า… → ทั่วไป → **ตอบคำขออนุญาตของ Claude Code จาก Angeling** (เปิดอยู่เป็นค่าเริ่มต้น)

ปิดแล้ว หรือเมื่อ Angeling ไม่ได้เปิดอยู่ hook จะจบทันทีโดยไม่หน่วง Claude Code

## ต้องมีอะไร

- ติดตั้ง hook ของ Claude Code แล้ว (ตัวติดตั้งทำให้เอง ถ้าเคยติดตั้งเวอร์ชันเก่า ให้อัปเดตหรือรันตัวติดตั้งอีกครั้ง เพื่อเพิ่ม `permit.sh`)
- `jq` (ตัวเดียวกับที่ hook หลักใช้)

## หลักการทำงาน

`~/.claude/angeling-pet/permit.sh` ลงทะเบียนเป็น hook `PermissionRequest` (timeout 600 วินาที):

1. ถ้าไม่มีไฟล์ `permits/enabled` หรือ Angeling ไม่ได้เปิดอยู่ จบทันที
2. เขียนคำขอลง `permits/<id>.json` (project, เครื่องมือ, คำสั่งหรือชื่อไฟล์, pid ของ hook, คำถามและตัวเลือก, ข้อความเดิมและข้อความใหม่ของการแก้ไฟล์)
3. รอไฟล์ `permits/<id>.answer` ที่แอปเขียนเมื่อกดปุ่ม (`allow`, `always` หรือ `deny`; สำหรับคำถามเป็น JSON `{"คำถาม": "ตัวเลือก"}` ถ้าเลือกหลายข้อจะคั่นด้วย `, `) แล้วตอบ Claude Code
4. ถ้าตอบใน Claude Code ก่อน Claude Code จะหยุด hook และ hook จะลบไฟล์คำขอของตัวเอง แอปก็ลบคำขอที่ hook ตายไปแล้วหรือเก่ากว่า 15 นาทีด้วย
