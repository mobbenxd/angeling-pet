# คู่มือ Angeling Pet

**Angeling** คือเพ็ตลอยบนเดสก์ท็อป macOS ที่คอยบอกว่างาน Claude Code แต่ละ session กำลังทำอะไรอยู่ อันไหนรอคุณตอบ และอันไหนเสร็จแล้ว คลิกเพื่อกระโดดไปที่ session นั้นได้ทันที นอกจากนี้ยังช่วย**ตั้งเตือน** (บันทึกลงปฏิทินและส่งเสียงเตือนเมื่อถึงเวลา) และบอกจำนวนข้อความ LINE ที่ยังไม่อ่านได้ด้วย

> **ติดตั้งครั้งแรก?** เริ่มที่ [ความต้องการของระบบ](Requirements.md) แล้วทำตาม [การติดตั้ง](Installation.md) ใช้เวลาประมาณ 5 นาที
