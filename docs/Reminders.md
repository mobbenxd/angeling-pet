# ตั้งเตือน

บอก Angeling ว่าจะทำอะไร วันไหน เวลาไหน แล้ว Angeling จะ:
- **เพิ่ม event ลงแอป Calendar** (ยาว 30 นาที) จึงเห็นในปฏิทินทุกเครื่องที่ซิงก์บัญชีเดียวกัน เช่น iCloud หรือ Google
- **เตือนเมื่อถึงเวลา:** โผล่ออกมา (แม้จะซ่อนอยู่) ส่งเสียงเตือน แสดง emote `/omg` และขึ้นแถวสีส้มค้างไว้จนกว่าคุณจะกดรับ

## ตั้งเตือน

1. กด **⌥⌘R** หรือคลิกขวาที่ Angeling (หรือไอคอนในแถบเมนู) → **⏰ ตั้งเตือน…**
2. กรอก **จะทำอะไร** เช่น `ประชุมทีม`
3. เลือก **เมื่อไร** (ค่าเริ่มต้นคือครึ่งชั่วโมงถัดไป) หรือกดปุ่มลัด `+15 นาที` / `+1 ชม.` / `พรุ่งนี้ 9:00`
4. เลือกว่าจะ **เพิ่มลงปฏิทิน** ไหน (Angeling จำปฏิทินที่เลือกล่าสุดไว้ให้)
5. กด **ตั้งเตือน** (หรือ Enter)

ครั้งแรก macOS จะถามว่าให้ Angeling เข้าถึงปฏิทินได้ไหม ให้กด **Allow Full Access** ถ้าไม่ให้ Angeling ก็ยังเตือนได้ แต่จะไม่เพิ่ม event ลงปฏิทิน

## เมื่อถึงเวลา

| สิ่งที่เกิดขึ้น | รายละเอียด |
|---|---|
| Angeling โผล่ | แม้จะซ่อนไว้ (⌥⌘A) หรือซ่อนบับเบิลไว้ แถวเตือนก็จะขึ้น |
| เสียง | เสียง Level Up ของ Ragnarok ดัง 3 ครั้ง แล้วดังซ้ำทุก 1 นาทีนาน 5 นาที |
| แถวสีส้ม "⏰ ถึงเวลาแล้ว!" | อยู่บนสุดของบับเบิล ค้างไว้จนกว่าจะกดรับ |
| ท่าทาง | กระโดด แล้วโบกมือ พร้อม emote `/omg` |

| ทำอะไรกับแถวสีส้ม | ผลลัพธ์ |
|---|---|
| คลิก | ทำแล้ว: แถวหายไป (event ในปฏิทินยังอยู่) |
| คลิกขวา → เลื่อนไป 5 / 10 / 30 นาที / 1 ชั่วโมง | เตือนอีกครั้งตามเวลาที่เลือก (ไม่ย้าย event ในปฏิทิน) |
| คลิกขวา → ลบการเตือน | เลิกเตือน |

ถ้าเครื่องหลับหรือ Angeling ปิดอยู่ตอนถึงเวลา จะเตือนทันทีที่กลับมาเปิด

**15 นาทีก่อนถึงเวลา** จะมีแถว "⏰ อีก N นาที" ขึ้นในบับเบิลด้วย

## จัดการการเตือน

เมนู → **การเตือนที่ตั้งไว้ (N)** แสดงทุกการเตือนพร้อมเวลา ชี้ที่แต่ละรายการเพื่อ:
- **ลบการเตือน (เก็บ event ในปฏิทินไว้)**
- **ลบทั้งการเตือนและ event ในปฏิทิน**

### แก้ไขจากแอป Calendar ก็ได้
- **ย้าย event** ไปวันหรือเวลาอื่น → Angeling เปลี่ยนเวลาเตือนตาม
- **เปลี่ยนชื่อ event** → ข้อความเตือนเปลี่ยนตาม
- **ลบ event** → การเตือนถูกยกเลิก

## เสียงเตือน

เสียงเริ่มต้นคือ **เสียง Level Up ของ Ragnarok Online** 🎺 (ตัวติดตั้งดาวน์โหลดมาให้จาก [MyInstants](https://www.myinstants.com/en/instant/level-up-ragnarok/) และไม่ได้รวมอยู่ใน repo เพราะเป็นลิขสิทธิ์ของ Gravity)

เมนู → **เสียงเตือน** เลือก Level Up (Ragnarok), Glass, Ping, Hero, Submarine, Funk หรือ **ปิดเสียง** เลือกแล้วจะได้ยินตัวอย่างทันที

ถ้าดาวน์โหลดเสียง Level Up ไม่สำเร็จ จะใช้ Glass แทน รัน `./install.sh` ซ้ำเพื่อลองโหลดใหม่

เสียงดังตามระดับเสียงของเครื่อง ถ้าปิดเสียงเครื่องไว้หรือเปิด Focus mode ก็อาจไม่ได้ยิน แต่แถวสีส้มยังขึ้นตามปกติ

## หมายเหตุ

- **หลัง build หรือติดตั้งใหม่ macOS อาจถามสิทธิ์ปฏิทินซ้ำ** เพราะ Angeling เซ็นแบบ ad-hoc
- Angeling ไม่ได้ตั้งการแจ้งเตือนของ Calendar เอง ถ้าอยากให้มือถือเตือนด้วย ให้เปิด event ในแอป Calendar แล้วเพิ่ม Alert
- การเตือนเก็บไว้ที่ `~/.claude/angeling-pet/reminders.json`

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| ช่อง "เพิ่มลงปฏิทิน" กดไม่ได้ | ยังไม่ได้ให้สิทธิ์ปฏิทิน: เมนู → **ให้สิทธิ์ปฏิทิน…** แล้วเปิด Angeling ใน System Settings → Privacy & Security → Calendars ให้เป็น Full Access |
| ไม่มีปฏิทินให้เลือก | เปิดแอป Calendar แล้วเพิ่มบัญชีหรือสร้างปฏิทินก่อน (ปฏิทินที่อ่านอย่างเดียว เช่น วันหยุด จะไม่แสดง) |
| ไม่มีเสียง | เช็คเมนู → เสียงเตือน ว่าไม่ได้เลือก "ปิดเสียง" และเครื่องไม่ได้ปิดเสียงอยู่ |
| หน้าต่างตั้งเตือนไม่ขึ้นมาด้านหน้า | กด ⌥⌘R อีกครั้ง หรือเปิดจากไอคอนในแถบเมนู |
| ⌥⌘R ไม่ทำงาน | แอปอื่นอาจใช้คีย์นี้อยู่แล้ว ให้เปิดจากเมนูแทน |
