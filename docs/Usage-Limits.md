# Limit การใช้งาน Claude

Angeling แสดงว่าใช้ limit ของ Claude ไปแล้วเท่าไร ตามที่บัญชีนั้นมีจริง ปิดไว้ตั้งแต่แรก

## เปิดใช้

เมนู → **ตั้งค่า… → Claude limit** แล้วเปิด **แสดง limit การใช้งาน Claude**

ตัวเลขจะขึ้นภายในไม่กี่วินาที ระหว่างนั้นหน้าตั้งค่าจะเขียนว่า "รอข้อมูลจาก Claude…"

ต้องใช้ Claude Code ที่ login ด้วยบัญชี Claude.ai (Pro / Max / Ultra / Team) ถ้าใช้ API key จะไม่มีข้อมูล limit

## แสดงที่ไหน

| ตอนไหน | หน้าตา |
|---|---|
| บับเบิลเปิดอยู่ | แถวบนสุดของบับเบิล เช่น `5hrs. 40% · weekly 62%` |
| ไม่มี limit 5 ชั่วโมง แต่มี limit รายสัปดาห์แยกของรุ่น (เช่น Ultra ที่ verify แล้ว) | `Fable 30% · weekly 62%` ถ้ามีหลายรุ่น จะขึ้นรุ่นที่ใช้ไปมากที่สุด |
| มีแค่ limit รายสัปดาห์ | `weekly 71% · รีเซ็ต จ. 11:00` |
| ซ่อนบับเบิล หรือไม่มีงาน | ใต้ Angeling มีหลอดพลัง และป้ายตัวเลขใต้หลอดที่แสดงข้อความเดียวกับบับเบิล 5 ชั่วโมงขึ้นก่อนเสมอเพราะหมดเร็วกว่า |
| ยังไม่มีข้อมูล | ป้ายใต้ Angeling เขียนว่า `limit: รอข้อมูล…` |

ตั้งค่า… → Claude limit → **แสดงที่** เปลี่ยนได้:

| ตัวเลือก | ผล |
|---|---|
| บนบับเบิล (ใต้ Angeling เมื่อซ่อนบับเบิล) | ค่าเริ่มต้น ตามตารางด้านบน |
| บนบับเบิลและใต้ Angeling | แถวบนบับเบิล และหลอด / ตัวเลขใต้ Angeling ตลอด |
| ใต้ Angeling อย่างเดียว | ไม่มีแถว limit บนบับเบิล |

Angeling ไม่ได้ดูชื่อแพ็กเกจ แต่แสดงตามรายการ limit ที่ Claude ส่งมา แพ็กเกจไหนมี limit อะไรก็ขึ้นตามนั้น

ชี้ที่แถว หลอด หรือป้ายเพื่อดูทุก limit พร้อมเวลารีเซ็ตและเวลาที่เหลือ รวมถึง limit รายสัปดาห์แยกของแต่ละรุ่น หมวด Claude limit ในหน้าตั้งค่าก็แสดงข้อมูลเดียวกัน

สีบอกว่าใช้ไปแค่ไหน: ฟ้าเมื่อต่ำกว่า 50% เหลืองเมื่อ 50–69% ส้มเมื่อ 70–85% แดงเมื่อเกิน 85%

| เครื่องหมาย | ความหมาย |
|---|---|
| `weekly 40%▲` | ใช้เร็วกว่าเวลาที่ผ่านไป: ใช้แล้วอย่างน้อย 25% และนำเวลาอยู่ 10 จุดขึ้นไป |
| `5hrs. 92% (18:20)` | เกิน 85% แล้ว วงเล็บคือเวลารีเซ็ต |
| ตัวเลขจางลง | ตัวเลขเก่าเกิน 30 นาที token อาจหมดอายุ ลองใช้ Claude Code สักครั้ง |

ถ้าเปิดหลาย limit จนป้ายใต้ Angeling ยาวเกิน ป้ายจะซ่อน limit แยกรุ่นที่ใช้น้อยที่สุดก่อน `5hrs.` กับ `weekly` อยู่เสมอ ส่วน limit ที่ซ่อนยังดูได้จาก tooltip tooltip และหน้าตั้งค่ายังบอกด้วยว่าตัวเลขอัปเดตเมื่อไร

เมื่อใช้ไปถึง 90% Angeling จะทำหน้า `/omg` หนึ่งครั้งต่อรอบรีเซ็ต

## เลือกตัวเลขที่จะแสดง

ตั้งค่า… → Claude limit มีสวิตช์ของทุก limit ที่บัญชีนี้มี (เช่น weekly, Fable, 5hrs.) เปิดตัวไหน ตัวนั้นจะขึ้นบนบับเบิลและป้าย ปิดหมดจะไม่แสดง limit ที่ Angeling แต่ยังดูในหน้าตั้งค่าได้

ถ้ายังไม่ได้เลือก จะแสดงสัปดาห์กับ 5 ชม. แพ็กเกจที่ไม่มี 5 ชม. จะแสดงสัปดาห์กับรุ่นที่ใช้ไปมากที่สุด ถ้าเคยตั้ง "limit ที่แสดง" ใน 1.11 ไว้ จะใช้ค่านั้นจนกว่าจะกดสวิตช์

Angeling ทำหน้า `/omg` เมื่อถึง 90% ของทุก limit แม้ limit นั้นจะปิดอยู่

## หลอดพลัง

มี 2 หลอดซ้อนกัน แต่ละหลอดมีชื่อกำกับด้านหน้า หลอดบนคือ `5hrs.` หลอดล่างคือ `weekly` เรียงตามตัวเลขด้านล่าง ถ้าบัญชีไม่มี limit 5 ชั่วโมง หลอดบนจะเป็น limit แยกรุ่นที่แสดงอยู่ (เช่น Fable) ถ้าไม่มีก็เหลือหลอดเดียว สีของแต่ละหลอดคิดจาก % ที่ใช้ไปของหลอดนั้น: ฟ้า เหลืองตั้งแต่ 50% ส้มตั้งแต่ 70% และแดงเกิน 85% ถ้าใช้ไปน้อยทั้งคู่ ทั้งสองหลอดจึงเป็นสีฟ้า

ในธีม Liquid Glass บน macOS 26 ขึ้นไป พื้นหลังของหลอดและป้ายตัวเลขจะเป็น Liquid Glass เหมือนบับเบิล

ตั้งค่า… → Claude limit → **ใต้ Angeling** เลือกได้ว่าจะแสดง **หลอดพลังและตัวเลข** (ค่าเริ่มต้น), **หลอดพลังอย่างเดียว** หรือ **ตัวเลขอย่างเดียว** ระหว่างที่ยังไม่มีข้อมูล จะแสดงแค่ป้าย `limit: รอข้อมูล…`

ตั้งค่าเพิ่มเติมในหมวดเดียวกัน:

| ตั้งค่า | ตัวเลือก |
|---|---|
| **ขอบหลอดพลัง** | เปิด (ค่าเริ่มต้น) หรือปิดขอบสีอ่อนรอบหลอด |

## ใช้ไปแล้ว หรือเหลืออยู่

ตั้งค่า… → Claude limit → **แสดงเป็น** เลือกได้ว่าจะแสดง % ที่**ใช้ไปแล้ว** (ค่าเริ่มต้น เหมือน `/usage` ใน Claude Code) หรือ % ที่**เหลืออยู่** แบบหลอด HP ที่ลดลงเรื่อยๆ

สีคิดจากส่วนที่ใช้ไปเสมอ เหลือน้อยจึงเป็นสีแดงทั้งสองแบบ

## ทำงานอย่างไร

Angeling อ่านตัวเลขจาก 2 ทาง แต่ละทางเก็บไฟล์ของตัวเองใน `~/.claude/angeling-pet/` ถ้าตัวเลขจาก API อายุไม่เกิน 15 นาทีจะใช้ตัวนั้น ไม่อย่างนั้นใช้ทางที่ตัวเลขเปลี่ยนล่าสุด

**1. usage API ของ Claude** (ทางหลัก ทุก 5 นาที เก็บใน `limits-api.json`) เป็นตัวเลขชุดเดียวกับ `/usage` ใน Claude Code ใช้ได้ไม่ว่าจะใช้ Claude Code ผ่าน Terminal หรือแอป Claude desktop

- ใช้ login ของ Claude Code ที่มีอยู่แล้ว Angeling อ่าน token จาก Keychain (`Claude Code-credentials`) ผ่าน `/usr/bin/security` หรือจาก `~/.claude/.credentials.json` ถ้า macOS ถามสิทธิ์ ให้กด **Always Allow** (ถ้าไม่ตอบภายใน 20 วินาที Angeling จะข้ามรอบนั้นไป) token ที่อ่านแล้วจะจำไว้จนหมดอายุ Keychain จึงถูกอ่านครั้งเดียวต่อ token
- Angeling แค่อ่าน token ไม่ต่ออายุให้ ถ้า token หมดอายุ ตัวเลขจะค้างค่าล่าสุดไว้จนกว่าจะใช้ Claude Code อีกครั้ง
- **ความเป็นส่วนตัว:** ระหว่างเปิด limit ไว้ Angeling จะส่ง token นี้ไปที่ `api.anthropic.com` ทุก 5 นาที ไม่ส่งไปที่อื่น ปิด limit แล้วจะหยุดส่ง
- วิธีนี้ดัดแปลงมาจาก [CodexBar](https://github.com/steipete/CodexBar) API นี้ไม่มีเอกสารทางการ จึงอาจเปลี่ยนได้ ถ้าใช้ไม่ได้ ยังมีทางที่ 2

**2. status line ของ Claude Code** (เก็บใน `limits.json`) Claude Code ส่งข้อมูล limit ให้เฉพาะ status line ไม่ได้ส่งให้ hook ทางนี้จะอัปเดตเฉพาะตอนใช้ `claude` ใน Terminal ตอนเปิดใช้ Angeling จะ:

1. สำรอง `~/.claude/settings.json` ไว้ที่ `settings.json.angeling-backup`
2. เก็บคำสั่ง status line เดิมของคุณ (ถ้ามี) ไว้ใน `~/.claude/angeling-pet/statusline-orig.json`
3. ตั้ง status line เป็น `~/.claude/angeling-pet/statusline.sh` ซึ่งบันทึกข้อมูลลง `limits.json` แล้วเรียก status line เดิมของคุณต่อ หน้าจอ Claude Code จึงเหมือนเดิม session ใหม่ที่ยังไม่มีตัวเลข จะไม่เขียนทับตัวเลขที่เก็บไว้

ถ้าตั้ง status line ไม่สำเร็จ (เช่น `settings.json` เป็น JSON ที่ผิด) Angeling จะแจ้งเตือน แต่ยังเปิด limit จาก API ให้ตามปกติ

ตอนปิด Angeling จะคืน status line เดิมให้ แต่เก็บ `limits.json` และ `limits-api.json` ไว้ เปิดใหม่จึงเห็นตัวเลขล่าสุดทันที ถ้าคุณเปลี่ยน status line เป็นอย่างอื่นไปแล้ว Angeling จะไม่แตะไฟล์ `uninstall.sh` ก็คืนให้เหมือนกัน

ไฟล์ `settings.json` จะถูกจัดรูปแบบใหม่ (ลำดับ key และการเว้นวรรคเปลี่ยน) แต่ค่าเหมือนเดิมทุกอย่าง
