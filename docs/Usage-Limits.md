# Limit การใช้งาน Claude, Codex และ AGY

Angeling แสดงว่าใช้ limit ของ Claude, Codex และ AGY (Antigravity CLI) ไปแล้วเท่าไร ทั้ง limit รายสัปดาห์และ limit 5 ชั่วโมง ปิดไว้ตั้งแต่แรก เปิดแต่ละตัวแยกกันได้

## เปิดใช้

เมนู → **ตั้งค่า… → limit** แล้วเปิด **แสดง limit การใช้งาน Claude**, **Codex** หรือ **AGY**

แต่ละตัวมีไอคอนของค่ายนั้นกำกับ โดยใช้ไอคอนของแอปที่ติดตั้งอยู่ในเครื่อง (แอป Claude, แอป Codex / ChatGPT, แอป Antigravity) ถ้าไม่มีแอปนั้นจะใช้ไอคอนสีประจำตัวแทน

อยากได้โลโก้ที่คมกว่าไอคอนแอป ให้วางไฟล์โลโก้ของคุณเองไว้ที่ `~/.claude/angeling-pet/icons/` ตั้งชื่อ `claude`, `codex` หรือ `agy` นามสกุล `.pdf`, `.svg` หรือ `.png` (PNG ควรใหญ่อย่างน้อย 64×64) แล้วเปิด Angeling ใหม่

ตัวเลขจะขึ้นภายในไม่กี่วินาที ระหว่างนั้นหน้าตั้งค่าจะเขียนว่า "รอข้อมูลจาก Claude…"

ต้องใช้ Claude Code ที่ login ด้วยบัญชี Claude.ai (Pro / Max) ถ้าใช้ API key จะไม่มีข้อมูล limit Codex ก็เช่นกัน ต้อง login ด้วยบัญชี ChatGPT ส่วน AGY ต้อง login ใน `agy` ไว้แล้ว

ถ้าเปิดมากกว่าหนึ่งตัว แต่ละตัวจะมีแถวบนบับเบิลและหลอดใต้ Angeling ของตัวเอง โดยมีชื่อนำหน้า เช่น `Codex  สัปดาห์ 12% · 5 ชม. 88%` เรียง Claude, Codex, AGY จากบนลงล่าง ตัวเลือกด้านล่าง (แสดงที่ แสดงเป็น ฯลฯ) ใช้ร่วมกันทุกตัว

## แสดงที่ไหน

| ตอนไหน | หน้าตา |
|---|---|
| บับเบิลเปิดอยู่ | แถวบนสุดของบับเบิล เช่น `สัปดาห์ 62% · 5 ชม. 40%` |
| บัญชีไม่มี limit 5 ชั่วโมง | `สัปดาห์ 71% · รีเซ็ต จ. 11:00` |
| ซ่อนบับเบิล หรือไม่มีงาน | ใต้ Angeling มีหลอดพลัง และป้ายตัวเลขใต้หลอด เช่น `5 ชม. 40% · สัปดาห์ 62%` (5 ชั่วโมงขึ้นก่อนเพราะหมดเร็วกว่า) |
| บัญชีมี limit รายสัปดาห์ของ Fable แยก | ต่อท้ายด้วย `Fable 50%` ทั้งบนบับเบิลและป้ายใต้ Angeling เช่น `สัปดาห์ 40% · 5 ชม. 12% · Fable 50%` |
| ยังไม่มีข้อมูล | ป้ายใต้ Angeling เขียนว่า `limit: รอข้อมูล…` (หรือ `AGY: รอข้อมูล…` เมื่อเปิดหลายตัว) |

ตั้งค่า… → limit → **แสดงที่** เปลี่ยนได้:

| ตัวเลือก | ผล |
|---|---|
| บนบับเบิล (ใต้ Angeling เมื่อซ่อนบับเบิล) | ค่าเริ่มต้น ตามตารางด้านบน |
| บนบับเบิลและใต้ Angeling | แถวบนบับเบิล และหลอด / ตัวเลขใต้ Angeling ตลอด |
| ใต้ Angeling อย่างเดียว | ไม่มีแถว limit บนบับเบิล |

ชี้ที่แถว หลอด หรือป้ายเพื่อดูเวลารีเซ็ตและเวลาที่เหลือ หมวด limit ในหน้าตั้งค่าก็แสดงข้อมูลเดียวกัน

เมนูจากไอคอนแถบเมนูก็แสดง limit ของทุกตัวที่เปิดไว้ แต่ละตัวมีไอคอนและชื่อ ใต้ชื่อมีบรรทัดละ limit (5 ชม. ก่อน แล้วตามด้วยสัปดาห์) พร้อมเวลารีเซ็ตและเวลาที่เหลือ เช่น `5 ชม. เหลือ 93% · รีเซ็ต 11:03 (อีก 1 ชม. 19 นาที)` บรรทัดเหล่านี้แสดงครบทั้งสอง limit เสมอ ไม่ขึ้นกับตัวเลือก **limit ที่แสดง** คลิกบรรทัดใดก็ได้เพื่อเปิดหมวด limit ในหน้าตั้งค่า

สีบอกว่าใช้ไปแค่ไหน: ฟ้าเมื่อต่ำกว่า 60% ส้มเมื่อ 60–85% แดงเมื่อเกิน 85%

เมื่อใช้ไปถึง 90% Angeling จะทำหน้า `/omg` หนึ่งครั้งต่อรอบรีเซ็ต

## หลอดพลัง

มี 2 หลอดซ้อนกัน หลอดบนที่หนากว่าคือรายสัปดาห์ หลอดล่างคือ 5 ชั่วโมง ถ้าบัญชีไม่มี limit 5 ชั่วโมง จะเหลือหลอดเดียว สีของแต่ละหลอดคิดจาก % ที่ใช้ไปของหลอดนั้น: ฟ้า ส้มตั้งแต่ 60% และแดงเกิน 85% ถ้าใช้ไปน้อยทั้งคู่ ทั้งสองหลอดจึงเป็นสีฟ้า ถ้ามี limit ของ Fable จะมีหลอดบางอีกหลอดอยู่บนสุด

ตั้งค่า… → limit → **ใต้ Angeling** เลือกได้ว่าจะแสดง **หลอดพลังและตัวเลข** (ค่าเริ่มต้น), **หลอดพลังอย่างเดียว**, **ตัวเลขอย่างเดียว** หรือ **ไอคอนและตัวเลข (กระชับ)** ซึ่งเป็นป้ายเล็กมีไอคอนของแต่ละค่ายกับตัวเลขเดียว (5 ชม. ถ้ามี ไม่อย่างนั้นสัปดาห์) วางเรียงกันในแถวเดียว ป้ายเปลี่ยนเป็นสีส้มหรือแดงเมื่อใช้เกิน 60% / 85% ถ้ามี limit ของ Fable ป้ายของ Claude จะมีตัวเลขของ Fable ต่อท้าย เช่น `88 Fable 50` ชี้ที่ป้ายเพื่อดูครบทุก limit ระหว่างที่ยังไม่มีข้อมูล จะแสดงแค่ป้าย `limit: รอข้อมูล…`

ตั้งค่าเพิ่มเติมในหมวดเดียวกัน:

| ตั้งค่า | ตัวเลือก |
|---|---|
| **limit ที่แสดง** | 5 ชม. และสัปดาห์ (ค่าเริ่มต้น), 5 ชม. อย่างเดียว หรือสัปดาห์อย่างเดียว มีผลกับแถวบนบับเบิล หลอด และตัวเลข ถ้าเลือกแบบเดียวจะแสดงเวลารีเซ็ตด้วย ถ้าบัญชีไม่มี limit ที่เลือก จะแสดงอันที่มีแทน limit ของ Fable ไม่ขึ้นกับตัวเลือกนี้ (ดู **แสดง limit ของ Fable**) หน้าตั้งค่ายังแสดงครบทั้งสองอัน และ `/omg` ตอนถึง 90% ยังดูทุกอัน รวม Fable |
| **แสดง limit ของ Fable** | เปิด (ค่าเริ่มต้น) หรือปิด อยู่ใต้ตัวเลขของ Claude ถ้าปิด จะไม่แสดง limit ของ Fable ที่ไหนเลย ทั้งบับเบิล ใต้ Angeling เมนู และหน้าตั้งค่า และไม่ทำหน้า `/omg` ตอน Fable ถึง 90% |
| **ขนาดหลอดพลัง** | เล็ก (ค่าเริ่มต้น), กลาง หรือใหญ่ ปรับทั้งความยาวและความหนาของหลอด |
| **ขอบหลอดพลัง** | เปิด (ค่าเริ่มต้น) หรือปิดขอบสีอ่อนรอบหลอด |

## ใช้ไปแล้ว หรือเหลืออยู่

ตั้งค่า… → limit → **แสดงเป็น** เลือกได้ว่าจะแสดง % ที่**ใช้ไปแล้ว** (ค่าเริ่มต้น เหมือน `/usage` ใน Claude Code) หรือ % ที่**เหลืออยู่** แบบหลอด HP ที่ลดลงเรื่อยๆ

สีคิดจากส่วนที่ใช้ไปเสมอ เหลือน้อยจึงเป็นสีแดงทั้งสองแบบ

## ทำงานอย่างไร (Claude)

Angeling อ่านตัวเลขจาก 2 ทาง แต่ละทางเก็บไฟล์ของตัวเองใน `~/.claude/angeling-pet/` ถ้าตัวเลขจาก API อายุไม่เกิน 15 นาทีจะใช้ตัวนั้น ไม่อย่างนั้นใช้ตัวที่ใหม่กว่า

ถ้าตัวเลขที่แสดงเก่ากว่า 30 นาที Angeling จะบอกเวลาของข้อมูลต่อท้าย เช่น `5 ชม. 40% · ข้อมูล พฤ. 17:54` และในเมนูจะมีบรรทัด "ข้อมูลเมื่อ … อาจไม่ตรงกับตอนนี้" ตัวเลขชุดนั้นอาจไม่ตรงกับ `/usage` แล้ว

**1. usage API ของ Claude** (ทางหลัก ทุก 5 นาที เก็บใน `limits-api.json`) เป็นตัวเลขชุดเดียวกับ `/usage` ใน Claude Code รวม limit รายสัปดาห์ที่แยกตามโมเดล (ตอนนี้คือ Fable) ซึ่งมีเฉพาะทางนี้ ใช้ได้ไม่ว่าจะใช้ Claude Code ผ่าน Terminal หรือแอป Claude desktop

- ใช้ login ของ Claude Code ที่มีอยู่แล้ว Angeling อ่าน token จาก Keychain (`Claude Code-credentials`) ผ่าน `/usr/bin/security` หรือจาก `~/.claude/.credentials.json` ถ้า macOS ถามสิทธิ์ ให้กด **Always Allow** (ถ้าไม่ตอบภายใน 20 วินาที Angeling จะข้ามรอบนั้นไป) token ที่อ่านแล้วจะจำไว้จนหมดอายุ Keychain จึงถูกอ่านครั้งเดียวต่อ token
- token ของ Claude Code อยู่ได้ไม่กี่ชั่วโมง ถ้าใช้แต่แอป Claude desktop (ซึ่ง login แยกของตัวเอง) จะไม่มีใครต่ออายุ token นี้ให้ เมื่อหมดอายุ Angeling จึงต่ออายุเองด้วย refresh token แบบเดียวกับที่ Claude Code ทำ (ส่งไปที่ `platform.claude.com`) แล้วเขียน token ใหม่กลับลง Keychain item เดิม ค่าอื่นใน item ไม่เปลี่ยน `claude` ใน Terminal จึงยัง login อยู่ตามปกติ
- ถ้าต่ออายุไม่สำเร็จ (เช่น refresh token หมดอายุ) ตัวเลขจะค้างค่าล่าสุดพร้อมเวลาของข้อมูล ให้เปิด `claude` ใน Terminal สักครั้ง (หรือ `/login` ใหม่)
- **ความเป็นส่วนตัว:** ระหว่างเปิด limit ไว้ Angeling จะส่ง token นี้ไปที่ `api.anthropic.com` ทุก 5 นาที และส่ง refresh token ไปที่ `platform.claude.com` เฉพาะตอนต่ออายุ ไม่ส่งไปที่อื่น ปิด limit แล้วจะหยุดส่ง
- วิธีนี้ดัดแปลงมาจาก [CodexBar](https://github.com/steipete/CodexBar) API นี้ไม่มีเอกสารทางการ จึงอาจเปลี่ยนได้ ถ้าใช้ไม่ได้ ยังมีทางที่ 2

**2. status line ของ Claude Code** (เก็บใน `limits.json`) Claude Code ส่งข้อมูล limit ให้เฉพาะ status line ไม่ได้ส่งให้ hook ทางนี้จะอัปเดตเฉพาะตอนใช้ `claude` ใน Terminal ตอนเปิดใช้ Angeling จะ:

1. สำรอง `~/.claude/settings.json` ไว้ที่ `settings.json.angeling-backup`
2. เก็บคำสั่ง status line เดิมของคุณ (ถ้ามี) ไว้ใน `~/.claude/angeling-pet/statusline-orig.json`
3. ตั้ง status line เป็น `~/.claude/angeling-pet/statusline.sh` ซึ่งบันทึกข้อมูลลง `limits.json` แล้วเรียก status line เดิมของคุณต่อ หน้าจอ Claude Code จึงเหมือนเดิม session ใหม่ที่ยังไม่มีตัวเลข จะไม่เขียนทับตัวเลขที่เก็บไว้

ถ้าตั้ง status line ไม่สำเร็จ (เช่น `settings.json` เป็น JSON ที่ผิด) Angeling จะแจ้งเตือน แต่ยังเปิด limit จาก API ให้ตามปกติ

ตอนปิด Angeling จะคืน status line เดิมให้ แต่เก็บ `limits.json` และ `limits-api.json` ไว้ เปิดใหม่จึงเห็นตัวเลขล่าสุดทันที ถ้าคุณเปลี่ยน status line เป็นอย่างอื่นไปแล้ว Angeling จะไม่แตะไฟล์ `uninstall.sh` ก็คืนให้เหมือนกัน

ไฟล์ `settings.json` จะถูกจัดรูปแบบใหม่ (ลำดับ key และการเว้นวรรคเปลี่ยน) แต่ค่าเหมือนเดิมทุกอย่าง

## ทำงานอย่างไร (Codex)

Codex ไม่ต้องตั้งค่าอะไร Angeling อ่านจาก 2 ทาง ใช้ตัวที่ใหม่กว่า

**1. usage API ของ ChatGPT** (ทุก 5 นาที เก็บใน `limits-codex.json`) ตัวเลขชุดเดียวกับ `/status` ใน Codex ใช้ token จาก `~/.codex/auth.json` (หรือ `$CODEX_HOME/auth.json`) แค่อ่าน ไม่ต่ออายุให้ ถ้า token หมดอายุจะข้ามไปจนกว่าจะใช้ Codex อีกครั้ง

**2. log session ล่าสุดของ Codex** (`~/.codex/sessions/…/rollout-*.jsonl`) Codex บันทึก limit ไว้หลังตอบทุกครั้ง ทางนี้ไม่ใช้เน็ต

**ความเป็นส่วนตัว:** ระหว่างเปิด limit ของ Codex Angeling จะส่ง token ไปที่ `chatgpt.com` ทุก 5 นาที (เมื่อ token ยังไม่หมดอายุ) ไม่ส่งไปที่อื่น และอ่านเฉพาะบรรทัดตัวเลข limit ใน log ไม่อ่านข้อความแชต

## ทำงานอย่างไร (AGY)

ทุก 5 นาที Angeling ถาม quota API ที่ `agy` ใช้เอง (`cloudcode-pa.googleapis.com`) แล้วเก็บใน `limits-agy.json` ตัวเลขเป็นของกลุ่มโมเดลที่ใช้ไปมากที่สุด (เช่น "Claude and GPT models")

- token อ่านจาก Keychain (service `gemini`, account `antigravity`) ที่ `agy` เก็บไว้ ผ่าน `/usr/bin/security` แค่อ่าน ไม่ต่ออายุให้ token ของ `agy` อยู่ได้ราว 1 ชั่วโมง ถ้าไม่ได้เปิด `agy` นานกว่านั้น ตัวเลขจะค้างค่าล่าสุดไว้จนกว่าจะเปิด `agy` อีกครั้ง
- **ความเป็นส่วนตัว:** ระหว่างเปิด limit ของ AGY Angeling จะส่ง token นี้ไปที่ `cloudcode-pa.googleapis.com` ทุก 5 นาที ไม่ส่งไปที่อื่น
- API นี้ไม่มีเอกสารทางการ จึงอาจเปลี่ยนได้
