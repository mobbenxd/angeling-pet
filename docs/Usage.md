# วิธีใช้งาน

## เมาส์

| ทำอะไร | ผลลัพธ์ |
|---|---|
| คลิก Angeling หรือพื้นบับเบิล | Angeling กระโดด แล้วเปิด session ที่ยังทำงานอยู่ล่าสุด (ดูจากเวลาอัปเดต) ถ้าไม่มี จะเปิด session ล่าสุดทั้งหมด |
| คลิกแถว session | เปิด session นั้น ถ้าเป็นแถวที่เสร็จแล้ว (สีเขียว) แถวจะหายไปด้วย |
| คลิกแถว LINE | เปิดแอป LINE |
| คลิกแถว Discord | เปิดแอป Discord |
| คลิกแถวเตือนสีส้ม | รับทราบ (คลิกขวาเพื่อเลื่อน) ดู [ตั้งเตือน](Reminders.md) |
| คลิก "+N อื่น ๆ" | ขยายรายการ |
| คลิกขวาที่แถว | ไปที่ session / ซ่อนแถวนี้ / เลือกสิ่งที่แสดง |
| คลิกขวาที่ Angeling | เมนูหลัก (ดูด้านล่าง) |
| ลาก Angeling | ย้ายที่ (Angeling จะวิ่งตาม) ตำแหน่งจะถูกจำไว้ |
| ชี้ที่ Angeling | ปุ่ม 👁 ทางซ้าย: ซ่อนบับเบิล หรือแสดงกลับมาแบบขยาย และเมาส์เปลี่ยนเป็นเคอร์เซอร์สามเหลี่ยมฟ้าขาวที่หมุนแบบ Ragnarok (ทุกธีม) |

แถวที่ซ่อนไว้จะกลับมาเองเมื่อ session นั้นมีความเคลื่อนไหวใหม่

## "เปิด session" ไปที่ไหน

| Session รันใน | ผลลัพธ์ |
|---|---|
| แอป Claude desktop | เปิด session นั้นตรงๆ (ผ่าน deep link) |
| Terminal.app | เลือกแท็บของ session นั้น |
| iTerm2 | เลือก session นั้น |
| kitty | เลือกหน้าต่างของ session นั้น (ต้องเปิด remote control ดูด้านล่าง) |
| herdr | สลับ herdr ไปที่ pane ของ session นั้น แล้วเรียก terminal ที่เปิด herdr อยู่ขึ้นมา |
| VS Code / Cursor / Windsurf | สลับไปหน้าต่างที่เปิด session นั้นอยู่ แล้วไปที่แท็บของ session ใน Claude extension ถ้าหาหน้าต่างไม่เจอจะแค่เรียกแอปขึ้นมา ไม่เปิดหน้าต่างใหม่ |
| อื่นๆ | เรียกแอปนั้นขึ้นมา |

ครั้งแรกที่สลับแท็บใน Terminal หรือ iTerm macOS อาจถามว่า Angeling ควบคุมแอปนั้นได้ไหม (Automation) ให้กด **OK**

ถ้าจะให้ kitty เลือกหน้าต่างได้ถูก (รวมถึงกรณีที่รัน herdr อยู่ใน kitty) ให้เพิ่ม 2 บรรทัดนี้ใน `~/.config/kitty/kitty.conf` แล้วปิดและเปิด kitty ใหม่ ถ้าไม่ได้เพิ่ม Angeling จะเรียก kitty ขึ้นมาได้ แต่ไม่ได้เลือกหน้าต่างให้

```
allow_remote_control socket-only
listen_on unix:/tmp/kitty-{kitty_pid}
```

เมื่อเปิดแล้ว โปรแกรมไหนก็ตามที่รันในเครื่องด้วย user ของคุณจะสั่งงาน kitty ผ่าน socket นี้ได้

## คีย์ลัด

| คีย์ | ผลลัพธ์ |

| ⌥⌘R | [ตั้งเตือน](Reminders.md) |

## เมนู

คลิกขวาที่ Angeling หรือคลิกไอคอนในแถบเมนู

| เมนู | ความหมาย |
|---|---|
| 🎁 อัปเดตเป็นเวอร์ชัน… | ขึ้นเมื่อมีเวอร์ชันใหม่ (ดู [อัปเดต](Updating-and-Uninstalling.md)) |
| ⏰ ตั้งเตือน… (⌥⌘R) | เปิดหน้าต่าง [ตั้งเตือน](Reminders.md) |
| การเตือนที่ตั้งไว้ (N) | ดูหรือลบการเตือน |
| ดูทุก session / ย่อรายการ | (คลิกขวาที่ Angeling) สลับแบบย่อ (2 แถวที่สำคัญที่สุด) กับแบบขยาย (ทุก session พร้อม prompt และ task list) |
| ซ่อน Angeling (⌥⌘A) | ซ่อนทั้งตัว เรียกกลับได้จากไอคอนแถบเมนู |
| ล้าง session ที่เสร็จแล้ว | ลบแถวที่เสร็จแล้วออกทั้งหมด |
| ตั้งค่า… (⌘,) | เปิดหน้าต่างตั้งค่า (ดูด้านล่าง) |
| ปิด Angeling | ปิดแอป (จะเปิดใหม่ตอน login ครั้งถัดไป หรือสั่ง `open ~/Applications/Angeling.app`) |

เมนูจากไอคอนแถบเมนูจะมีรายชื่อ session ด้วย คลิกเพื่อไปที่ session นั้นได้ ถ้าเปิด[limit การใช้งาน](Usage-Limits.md)ไว้ จะมี limit ของแต่ละตัวพร้อมเวลารีเซ็ตต่อจากรายชื่อ session ตัวเลขข้างไอคอนคือจำนวน session ที่ต้องดูตอนนี้ ถ้าไม่มีจะเป็นจำนวน session ที่กำลังทำหรือติดปัญหา ตรงกับป้ายบน Angeling

## ตั้งค่า

เมนู → **ตั้งค่า…** (หรือ ⌘, ตอนที่หน้าต่างของ Angeling อยู่ด้านหน้า) เปลี่ยนแล้วมีผลทันที ไม่ต้องกดบันทึก หน้าต่างจะเปิดที่หมวดล่าสุดที่ดูไว้ และปิดได้ด้วย ⌘W

| หมวด | ตั้งค่าอะไรได้ |
|---|---|
| ทั่วไป | ซ่อนกิจกรรม (ซ่อนบับเบิล เหลือแต่ Angeling กับป้ายตัวเลข), โผล่ออกมาเมื่อมีงานที่ต้องดู (ถ้าซ่อนไว้ จะโผล่กลับมาเองเมื่อ Claude รอคำตอบ), เสียงเตือนเมื่อมีงานที่ต้องดู และสิ่งที่แสดงในบับเบิล: งานที่สั่ง (prompt) / ข้อความล่าสุด / Task list |
| หน้าตา | ธีมของบับเบิล ดู [บับเบิลกิจกรรม](Activity-Bubble.md#ธีม) และตัวละคร ดู [เปลี่ยนเป็นเพ็ตตัวอื่น](Custom-Pet.md#เลือกตัวละคร-bomber) |
| แจ้งเตือน | [แจ้งเตือน LINE](LINE-Notifications.md), [แจ้งเตือน Discord](Discord-Notifications.md), เสียงเตือนของ[การเตือน](Reminders.md) และสิทธิ์ปฏิทิน |
| limit | เปิดหรือปิด [limit การใช้งาน](Usage-Limits.md) ของ Claude, Codex และ AGY แยกกัน, ดูตัวเลขตอนนี้, แสดงเป็น (ใช้ไปแล้ว / เหลืออยู่) แสดงที่ (บนบับเบิล / บนบับเบิลและใต้ Angeling / ใต้ Angeling อย่างเดียว) ใต้ Angeling แสดงอะไร (หลอดพลังและตัวเลข / หลอดพลังอย่างเดียว / ตัวเลขอย่างเดียว), limit ที่แสดง (5 ชม. และสัปดาห์ / 5 ชม. / สัปดาห์) และขอบหลอดพลัง |
| อัปเดต | ดูเวอร์ชัน อัปเดต ตรวจหาเวอร์ชันใหม่ และเปิดหรือปิดการตรวจอัตโนมัติ (ดู [อัปเดต](Updating-and-Uninstalling.md)) |
