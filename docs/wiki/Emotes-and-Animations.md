# Emote และท่าทาง

## Emote จาก Ragnarok Online

ลอยอยู่เหนือหัว Angeling เหมือนในเกม (ภาพจาก [iRO Wiki](https://irowiki.org/wiki/Emotes))

| Emote | แสดงเมื่อ | นาน |
|---|---|---|
| `/heh` | session ได้รับงานใหม่ | 3 วินาที |
| `/lv` | งานเสร็จ | 4 วินาที |
| `/wah` | Claude รอคำตอบจากคุณ | ค้างจนกว่าจะตอบ |
| `/omg` | tool ทำงานพลาด | 3 วินาที |
| `/swt` | session ทำงานต่อเนื่องเกิน 5 นาที | 3 วินาที |
| `/slur` | ว่างเกิน 10 นาที หรือโดนจิ้มตอนว่าง | 3 วินาที |

ถ้ามีหลายเหตุการณ์พร้อมกัน จะเลือกตามความสำคัญ: `/wah` > `/omg` > `/lv` > `/heh` > `/swt` > `/slur`

## ท่าทาง

| ท่า | เมื่อ |
|---|---|
| ลอยนิ่ง (idle) | ไม่มีงาน |
| วิ่ง | กำลังทำงาน |
| มองหา | กำลังอ่านหรือค้นหา |
| รอ | รอคำตอบจากคุณ |
| ล้ม | ติดปัญหา |
| กระโดด → โบกมือ | งานเพิ่งเสร็จ หรือโดนคลิก |
| วิ่งซ้าย/ขวา | กำลังถูกลาก |

## ไม่มี emote?

ไฟล์ emote อยู่ที่ `~/.claude/angeling-pet/emotes/` ถ้าตอนติดตั้งดาวน์โหลดไม่สำเร็จ (irowiki.org ล่มชั่วคราว) ให้รัน `./install.sh` ซ้ำ
