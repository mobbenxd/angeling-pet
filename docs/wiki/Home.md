# Angeling Pet Wiki

**Angeling** คือเพ็ตลอยบนเดสก์ท็อป macOS ที่คอยบอกว่างาน Claude Code แต่ละ session กำลังทำอะไรอยู่ อันไหนรอคุณตอบ และอันไหนเสร็จแล้ว คลิกเพื่อกระโดดไปที่ session นั้นได้ทันที นอกจากนี้ยังบอกจำนวนข้อความ LINE ที่ยังไม่อ่านได้ด้วย

> **ติดตั้งครั้งแรก?** เริ่มที่ [ความต้องการของระบบ](Requirements) แล้วทำตาม [การติดตั้ง](Installation) ใช้เวลาประมาณ 5 นาที
